NOVA V2 — Tienda web funcional
1. Abre index.html en un navegador.
2. Cambia el número de WhatsApp 573000000000 en index.html y script.js por el número real de la tienda.
3. Los productos/precios son demostrativos.
4. El carrito, productos y cambios del panel se guardan en localStorage del navegador.
5. Para una tienda real faltaría conectar pagos, base de datos, inventario y hosting.
