NOVA - CATALOGO PARA CLIENTES
================================

Archivos:
- index.html
- styles.css
- script.js

IMPORTANTE:
1. En script.js cambia:
   const WHATSAPP = "573000000000";
   por el número real de WhatsApp de NOVA, incluyendo código de país y sin + ni espacios.

2. Los precios incluidos son los precios de venta al cliente del catálogo.
   No se muestran precios de compra, costos ni márgenes.

3. Los bloques de producto actuales son visuales de demostración.
   Para usar fotografías reales, reemplaza cada bloque .visual por una imagen del producto o añade archivos /img.

4. El carrito funciona con localStorage y el botón de compra genera un pedido para WhatsApp.

PARA SUBIR A GITHUB PAGES:
- Reemplaza index.html, styles.css y script.js en tu repositorio.
- Haz Commit changes.
- GitHub Pages volverá a publicar la página automáticamente.

NOTA:
Antes de anunciar una prenda como disponible, confirma con el proveedor talla, color, inventario y costo final de envío.
